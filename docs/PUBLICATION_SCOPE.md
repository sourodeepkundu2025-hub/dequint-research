# Publication Scope and Source History

## Included

- Current `src/dequint` scientific source and the full current test suite.
- Scientific experiment, analysis, freeze, export and reporting utilities where
  they do not embed confidential reviewer text or private recovery paths.
- All retained numerical result families, including rejected/pre-review
  `batch_v1`, explicitly quarantined and excluded from scientific claims.
- Raw data, configurations, workloads, traces, QASM, Choi matrices and generated figures.
- Scientific protocols, result/backend/resource/claim/source ledgers.
- Four recovered standalone prototype files, historical isolated checks,
  arithmetic diagnostics and seven addon source checkpoints.

## Deliberately Excluded

- Patent/IDF-B disclosures, TRL questionnaires and private author correspondence.
- Raw reviewer reports, editorial email, response letters and scripts embedding
  that correspondence; current submission manuscript and private archive builders.
- Downloaded third-party papers, Wiley templates/class/style files, fonts,
  portrait images and manuscript assets with unreviewed redistribution rights.
- Upstream SeQUeNCe source/history: obtain the pinned public dependency separately.
- Credentials, environment secrets, personal machine locations, caches, rendered
  review screenshots, virtual environments and duplicate delivery ZIPs.
- Unrelated Q-VOLT, Q-OrchBench, HQFL-QNet, patent and employer project material.

This is a public **DEQUINT code/evidence** release, not a public backup of the
whole author workspace. No other private repository has its visibility changed.
The one-time authorization does not set a default for future publications.

## Traceability Without Publishing Private Git History

`history/snapshots.json` identifies seven local addon commits. Each corresponding
directory exports selected owned source/protocol files, not entire old commits,
private messages or upstream Git history. Historical modules are not installed
or collected by the current pytest configuration. Duplicate checkpoint files
are retained intentionally so that the development sequence remains inspectable.

The early prototypes are incomplete standalone experiments, not the submitted
integrated simulator. The current implementation was rebuilt and validated in
separately declared phases. The original source archives are preserved privately.

`PUBLICATION_PROVENANCE.json` records source labels and before/after hashes.
Privacy transformations replace only local-home/workspace strings in text where
present. The numerical source and data are not tuned to improve a reported result.
`PUBLIC_SHA256SUMS.json` records the distributed files' actual public identities.

The public Git history begins with this inspected snapshot. It does not claim
to reproduce every private conversation or every source version ever created.
